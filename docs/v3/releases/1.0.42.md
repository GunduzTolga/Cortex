# Cortex 1.0.42

Bu sürüm Cortex'i ilk kez kuran birinin karşılaştığı sorunları düzeltiyor:

- Kasa için klasör seçmek gerekmiyor: Belgeler içinde kendiliğinden açılıyor.
- Yalnız Claude Code değil, OpenCode, Codex, Gemini CLI ve Qwen Code da uygulamadan kurulabiliyor.
- "Claude Code kurulamadı" uyarısı, kurulum daha sürerken çıkmıyor.
- Sesle yazmanın kurulumu beklenmeden geçilebiliyor.
- Kurulum çubuğu takılmış gibi durmuyor.

## Güncelle

Yeni kurulum dosyasını (`Cortex Setup 1.0.42.exe`) çalıştır. Kasadaki motor bu sürümde değişmedi.

## Kasa kendiliğinden açılıyor

**İlk açılışta kasa `Belgeler\Cortex` olarak kendiliğinden oluşuyor.** Eskiden ilk açılışta bir klasör seçme penceresi çıkıyordu; ne seçileceğini bilmeyen biri burada takılıyordu. Belgeler OneDrive'a taşınmışsa kasa oraya açılır.

- Belgeler'de içinde başka dosyalar olan bir `Cortex` klasörü varsa ona dokunulmuyor; `Cortex 2` açılıyor.
- Obsidian kasası ya da başka bir klasör kullanmak isteyen **Başka klasör seç**'e basıyor.

## Her yapay zekâ aracı uygulamadan kuruluyor

**Kurulum ekranında ve boş sohbet ekranında artık her araç için bir "Kur" düğmesi var.** Eskiden yalnız Claude Code kurulabiliyordu; OpenCode kullanmak isteyen bunu uygulamadan yapamıyordu.

- Claude Code, Anthropic'in kendi kurucusuyla kuruluyor (Claude Pro ya da Max aboneliği ister).
- OpenCode, Codex, Gemini CLI ve Qwen Code npm ile kuruluyor. Bunun için bilgisayarda Node.js olmalı. Node.js yoksa açılan pencere önce onu kurmanı söylüyor.
- Kurulum bitince aracın giriş penceresi kendiliğinden açılıyor.
- Boş sohbet ekranında **Araçlar ve girişler** düğmesi, bütün araçların durumunu gösteren pencereyi açıyor.

## "Kurulamadı" uyarısı artık yalnız gerçekten kurulamadığında

**Kurulum penceresinden Cortex'e dönünce "Claude Code kurulamadı" yazmıyor.** Eskiden pencere değiştirmek araçların yeniden okunmasına yol açıyordu; kurulum bitmediği için araç henüz yoktu ve bu başarısızlık sayılıyordu. Şimdi karar yalnız kurulum penceresi kapandığında veriliyor.

## Sesle yazma beklemeden

**Sesle yazmanın kurulumu başlayınca kurulum ekranı sonraki adıma geçiyor.** Kurulum (birkaç yüz MB model indirmesi dahil) arka planda sürüyor ve bitince haber veriyor. Eskiden ekran ilerleme çubuğunu gösterip bekliyordu; kurulumun arka planda sürdüğü yazmıyordu.

## Kurulum çubuğu

**Yüzdesi bilinmeyen adımlarda (Python kurulumu, paket kurulumu) çubuk kayan bir şerit, yanında da geçen süre görünüyor.** Eskiden çubuk üçte birde sabit atıyordu ve kurulum takılmış gibi görünüyordu. Python kurulumunun 1-3 dakika sürebileceği de yazıyor.

## Geliştiriciler için

- `desktop/electron/services/auth.ts`: `INSTALLERS` npm ile kurulan dört aracı içeriyor (`opencode-ai`, `@openai/codex`, `@google/gemini-cli`, `@qwen-code/qwen-code`); `installScript` aracın adını ve npm yoksa Node.js uyarısını yazıyor. `clis.ts` `installedDirs` `%APPDATA%\npm`'i de içeriyor.
- `desktop/electron/services/vault.ts`: `defaultVaultDir`; `ipc.ts`: `vault:createDefault`, seçim sonrası işler `adoptVault`'ta toplandı.
- `Onboarding.tsx`: kurulum durumu araç başına (`Installing`); başarısızlık yalnız `authChanged(null)` (kurucu kapandı) ile.
- e2e: Belgeler klasörü koşuya özel (`app.setPath('documents', …)`); kasa önce kendiliğinden oluşuyor, sonra "Başka klasör seç" ile koşunun kasası seçiliyor.
- Testler: masaüstü 347 (338 geçti, 9 atlandı). e2e sunucuda koşulamadı (Electron ikilisi yok); Windows'ta koşulmalı.
