# Cortex 1.0.59

Kasayı yapay zeka araçlarına bağlamak artık masaüstünden: Ayarlar'daki yeni **Yapay zeka araçlarına bağla** bölümü Claude Code, Codex ve OpenCode için bu kasanın hazır satırını veriyor; Claude Code kuruluysa sana sorduktan sonra tek düğmeyle ekliyor.

Bu sürüm 1.0.43 ve sonrası kurulu bilgisayarlara kendiliğinden geliyor: Cortex arka planda indiriyor ve **Yeniden başlat** diyor. Kasadaki motor da kendiliğinden aynı sürüme getiriliyor; motorun kodu bu sürümde değişmedi, MCP kapısı 1.0.58'deki gibi.

## Ayarlar'da: Yapay zeka araçlarına bağla

- **Satır hazır.** Bölüm açık kasanın tam komutunu yazıyor: Cortex'in bu bilgisayarda çalıştığı Python'un yolu, kasanın `beyin.py`'si ve `mcp`. Claude Code için `claude mcp add --scope user cortex -- …`, Codex için `~/.codex/config.toml` tablosu, OpenCode için `opencode.json`; her birinin yanında **Kopyala**. Boşluklu ya da Türkçe harfli bir klasör adı terminalin okuyacağı gibi tırnaklanıyor (Windows'ta PowerShell'in, macOS ve Linux'ta kabuğun tırnakları).
- **Claude Code'a ekle.** Claude Code kuruluysa düğme, "ekleyelim mi?" diye sorduktan sonra Claude Code'un kendi `claude mcp add` komutunu çalıştırıyor; her projede kullanılmak üzere (`--scope user`). "Eklendi" ancak Claude Code bağlantıyı gösterince (`claude mcp get cortex`) yazıyor. Komut reddedilirse, çalışıp bağlantı görünmezse ya da Claude Code zamanında cevap vermezse bunu tek cümleyle söylüyor ve satırı kopyalayıp terminalde çalıştırmanı öneriyor.
- **Zaten bağlıysa söylüyor.** Ayarlar açılınca Claude Code'a "cortex" adıyla ne kayıtlı diye soruluyor: bu kasaysa "bağlı" yazıyor ve düğme çıkmıyor. Aynı adla başka bir kasa ya da sunucu varsa ona dokunmuyor; bu kasayı bağlamak için önce `claude mcp remove cortex` çalıştırmanı söylüyor.
- **Claude Code yoksa** yalnız kopyalanacak satırlar kalıyor.
- **Motor eskiyse** satırlar yerine "Cortex'i güncelle" cümlesi çıkıyor: dört araç (`search`, `context`, `capture`, `note_create`) 1.0.58'de tamamlandı. Daha eski bir motor, öncül projenin motoru, sürümü okunamayan ya da kapısı olmayan bir motor bağlanmıyor. Kasada Cortex'in hafızası yoksa ya da Python bulunamadıysa bölüm önce onu kurmanı söylüyor.
- Bölüm ayrıca yazan iki araca (`capture`, `note_create`) kalıcı izin vermemeni hatırlatıyor: her yazmadan önce sana sorulsun ([MCP belgesi](../MCP.md#yazma-ve-onay)).

## Güvenlik

- **Pencere hiçbir yol ya da komut göndermiyor.** Kasa uygulamanın açık tuttuğu kasa; Python ve Claude Code ana sürecin bulduğu programlar. Pencereden gelen bir yol ya da komut okunmuyor (testle sabit).
- **Kabuk yok.** Claude Code bir argüman listesiyle, ev klasöründen çalıştırılıyor; boşluk ya da Türkçe harf içeren yol olduğu gibi gidiyor.
- **Yol yalnız bu bölümde görünüyor.** Kopyalanacak satır kasanın ve Python'un tam yolunu içeriyor; uygulamanın öbür ekranları yol göstermemeye devam ediyor.

## Geliştiriciler için

- Köprüde yeni `window.cortex.mcp`: `status()` ve `addToClaude()`; kanallar `mcp:status` ve `mcp:addToClaude`, ikisi de argüman almıyor. Kod: `desktop/shared/mcp.ts`, `desktop/electron/services/mcp.ts`, `desktop/src/ui/McpSection.tsx`.
- `claude mcp get cortex` çıktısında kasanın `beyin.py` yolu aranıyor (Windows'ta büyük-küçük harf gözetmeden): çıkış 0 ve yol varsa `this`, yol yoksa `other`; "No MCP server named" (eski sürümlerde "No MCP server found with name") `none`; başka her şey `unknown`. `mcp get` sunucuyu başlatıp sağlığına baktığı için Claude Code'a 30 sn veriliyor.
- **MCP sözleşmesi değişmedi:** araç şeması özeti 1.0.58'deki gibi `c283cfa0…`; motor kodu değişmedi.
- Testler: `desktop/tests/mcp.test.ts` 8 test. Sahte bir `claude` CLI ile ekle, zaten var, aynı adla başka sunucu, ret, sessiz başarı, yavaş cevap, Claude Code yok; boşluklu ve Türkçe harfli yol, Windows ayırıcısı, satırın gerçek bir kabukta aynı kelimelere geri okunması. Her yeni test en az bir bozuk kodda (mutasyonla) düştüğü görülerek yazıldı. e2e smoke'ta 6 yeni kontrol ve köprü listesinde `mcp`.
- Gerçek bir Claude Code'a ekleme, Windows ve macOS'ta denenmedi.
